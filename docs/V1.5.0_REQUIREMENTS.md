## 0. 배경 및 목표

### 0.1 배경

개발자들이 자주 수행하는 이미지/비디오 처리 작업을 위해 다음과 같은 니즈가 있습니다:

- **이미지 처리**: 스크린샷 크롭, 썸네일 생성, 포맷 변환, 리사이즈
- **비디오 처리**: 썸네일 추출, 구간 자르기, 포맷 변환, 해상도 변경
- **프라이버시 우려**: 외부 서비스에 민감한 이미지/비디오를 업로드하기 꺼려함
- **빠른 작업**: 간단한 편집을 위해 무거운 전문 소프트웨어를 열기 번거로움

### 0.2 v1.5.0 목표

1. **Frontend-only 미디어 처리**

   - 서버 없이 브라우저에서 이미지/비디오 파일을 로드 → 편집(여러 기능 조합) → 결과 다운로드
   - "민감 데이터는 내 브라우저에서만 처리"라는 프로젝트 철학 유지

2. **파이프라인 기반 편집**

   - 여러 편집 단계를 조합하여 한 번에 실행
   - 프리셋 저장/공유 기능으로 반복 작업 효율화

3. **성능 최적화**

   - 대용량 처리 시 UI 프리징 방지 (Web Worker 기반)
   - 실시간 진행 상태(Progress) 표시
   - 작업 취소 기능

4. **모바일 대응**
   - 반응형 레이아웃
   - 터치 기반 인터랙션 지원

## 1. 범위

### 1.1 In Scope

#### ✨ **신규 Tool: Image Studio**

- 이미지 로드 (Drag & Drop, File Picker, Clipboard Paste)
- **Crop**: 자유비율, 고정비율(1:1, 4:3, 16:9), 사용자 지정 비율
- **Resize**: width/height 입력, 비율 잠금, 보간 품질 옵션
- **Rotate/Flip**: 90도 회전, 수평/수직 반전
- **Convert/Export**: PNG, JPEG, WebP 포맷, 품질 조절
- 파이프라인 조합 및 일괄 실행
- 프리셋 저장/불러오기/공유

#### ✨ **신규 Tool: Video Studio**

- 비디오 로드 (Drag & Drop, File Picker)
- **Thumbnail**: 특정 시점 프레임 이미지 추출
- **Trim**: 시작/종료 시간 지정하여 구간 추출
- **Cut**: 구간 제거 또는 구간 분할 (다중 클립 생성)
- **Crop**: 영상 영역 자르기
- **Resize**: 출력 해상도 변경
- **Export/Convert**: MP4, WebM 컨테이너, 품질 프리셋
- 파이프라인 조합 및 일괄 실행
- 진행률 표시 및 취소 기능

#### 🔧 **공통 기능**

- Chrome Extension 필요 없음 (순수 브라우저 기능만 사용)
- localStorage 설정 저장 (파일 바이너리 제외)
- 프리셋 공유 (설정 JSON을 URL fragment로 공유)
- i18n 지원 (en-US, ko-KR, ja-JP, zh-CN, es-ES)
- 키보드 단축키

### 1.2 Out of Scope (v1.5.0 제외)

- ❌ 서버사이드 처리
- ❌ 클라우드 저장/동기화
- ❌ 비디오 필터/효과 (색상 보정, 블러 등)
- ❌ 오디오 편집 (비디오 내 오디오는 원본 유지)
- ❌ 배치 처리 (여러 파일 동시 처리)
- ❌ 비디오 인코딩 고급 옵션 (비트레이트, 코덱 상세 설정)
- ❌ 멀티스레드 ffmpeg (SharedArrayBuffer/COOP/COEP 필요)
- ❌ GIF 생성/편집
- ❌ 워터마크/텍스트 오버레이

### 3.2.1 프리셋 관리 (Preset Management Modal)

프리셋은 **모달** 형태로 관리되며, 다음 기능을 제공합니다:

#### 프라이버시 고지

모달 상단에 다음 문구를 표시합니다:

> "Presets are stored locally in your browser only. They are never sent to any server. Use Export/Import to back up or transfer your presets."

#### 프리셋 저장

- **현재 설정 저장**: 현재 파이프라인 설정을 새 프리셋으로 저장
- **입력 필드**:
  - 프리셋 이름 (필수)
  - 설명 (선택)
- **저장 대상**: enable 상태, 각 단계별 설정값, export 설정
- **제외 대상**: 이미지/비디오 바이너리, crop 좌표 (이미지별 다름)

#### 프리셋 목록

- 저장된 프리셋 목록 표시
- 각 항목 정보: 이름, 설명, 생성일, 활성화된 단계 태그
- 클릭하여 불러오기
- 삭제 버튼

#### 내보내기/가져오기 (Export/Import)

| 기능          | 설명                                             |
| ------------- | ------------------------------------------------ |
| **Export**    | 모든 프리셋을 JSON 파일로 다운로드               |
| **Import**    | JSON 파일에서 프리셋 가져오기 (기존 프리셋 대체) |
| **Clear All** | 모든 프리셋 삭제 (확인 필요)                     |

- LocalStorage 기반 저장
- JSON 파일 내보내기/가져오기
- 모달 UI
- 프라이버시 고지 문구

### 3.3 성능/프리징 방지

#### 이미지 처리

- **1차 권장**: `createImageBitmap()` → Canvas 렌더 (메모리/속도 유리)
- **2차 권장**: OffscreenCanvas + Worker (메인스레드 프리징 방지)
- **폴백**: 메인 스레드 Canvas (Worker 미지원 환경)

#### 비디오 처리

- **필수**: ffmpeg.wasm 기반 전용 Worker에서만 실행
- **금지**: 메인 스레드에서 ffmpeg 실행
- **싱글톤**: ffmpeg 인스턴스는 1개만 유지 (메모리 누수 방지)

#### 진행 상태 표시

| 단계                | 설명                               |
| ------------------- | ---------------------------------- |
| `Loading engine...` | ffmpeg 코어 다운로드/초기화        |
| `Preparing...`      | 입력 파일 FS write, command 생성   |
| `Processing... N%`  | 진행률 + 경과 시간 + 예상 남은시간 |
| `Finalizing...`     | 출력 FS read → Blob 생성           |

#### 취소 기능

- **비디오**: Cancel 버튼 필수
- **구현**: Worker terminate 후 재생성 (가장 확실)
- **대안**: 작업 중단 API 시도 → 실패 시 terminate fallback

### 3.4 키보드 단축키 (공통)

### 3.5 모바일 대응

## 4. Image Studio (이미지 편집) 요구사항

### 4.1 상태(State) 정의

```typescript
type ImageStudioState = {
  // 파일 정보 (저장 제외, 런타임만)
  fileName?: string;
  fileSize?: number;
  originalWidth?: number;
  originalHeight?: number;

  // 파이프라인 단계 활성화
  cropEnabled: boolean;
  resizeEnabled: boolean;
  rotateEnabled: boolean;

  // Crop 설정
  cropAspectRatio: 'free' | '1:1' | '4:3' | '16:9' | 'custom';
  cropCustomRatio?: { width: number; height: number };
  cropArea?: { x: number; y: number; width: number; height: number };

  // Resize 설정
  resizeWidth?: number;
  resizeHeight?: number;
  resizeLockAspect: boolean;
  resizeMode: 'contain' | 'cover' | 'stretch';
  resizeQuality: 'low' | 'medium' | 'high';

  // Rotate/Flip 설정
  rotation: 0 | 90 | 180 | 270;
  flipHorizontal: boolean;
  flipVertical: boolean;

  // Export 설정
  exportFormat: 'png' | 'jpeg' | 'webp';
  exportQuality: number; // 0-100, JPEG/WebP만 적용
  exportSuffix: string; // 기본: ''
};
```

### 4.2 지원 기능(단계)

#### 4.2.1 Crop (필수)

**기능 요구사항**:

- FR-I-CROP-01: 프리뷰에서 드래그로 영역 지정
- FR-I-CROP-02: 비율 프리셋 선택 (자유, 1:1, 4:3, 16:9, 사용자 지정)
- FR-I-CROP-03: 사용자 지정 비율 입력 (width:height)
- FR-I-CROP-04: crop 영역 좌표(x, y, width, height) 수치 입력
- FR-I-CROP-05: 프리뷰에서 crop 영역 핸들로 조절
- FR-I-CROP-06: crop 영역 이동 (드래그)

**UI 요소**:

- 비율 선택 드롭다운
- 사용자 지정 비율 입력 필드 (custom 선택 시)
- 좌표 수치 입력 필드 (x, y, width, height)
- 프리뷰 오버레이 (crop 영역 외부 어둡게)

#### 4.2.2 Resize (필수)

**기능 요구사항**:

- FR-I-RESIZE-01: width/height 픽셀 값 입력
- FR-I-RESIZE-02: 비율 잠금 토글 (lock aspect ratio)
- FR-I-RESIZE-03: 비율 잠금 시 한쪽 값 변경하면 자동 계산
- FR-I-RESIZE-04: 리사이즈 모드 선택
  - `contain`: 비율 유지, 여백 허용 (투명 또는 색상)
  - `cover`: 비율 유지, 잘라서 채움
  - `stretch`: 비율 무시, 강제 맞춤
- FR-I-RESIZE-05: 보간 품질 선택 (low/medium/high)
  - Canvas `imageSmoothingQuality` 속성 사용

**UI 요소**:

- Width/Height 입력 필드 + 잠금 아이콘 토글
- 모드 선택 라디오/드롭다운
- 품질 선택 라디오/드롭다운

#### 4.2.3 Rotate/Flip (필수)

**기능 요구사항**:

- FR-I-ROTATE-01: 90도 단위 회전 (0°, 90°, 180°, 270°)
- FR-I-ROTATE-02: 수평 반전 (Flip Horizontal)
- FR-I-ROTATE-03: 수직 반전 (Flip Vertical)
- FR-I-ROTATE-04: 회전/반전은 순서대로 적용 (회전 → 수평 반전 → 수직 반전)

**UI 요소**:

- 회전 버튼 (시계방향 90°, 반시계방향 90°)
- 현재 회전 각도 표시
- 수평 반전 토글 버튼
- 수직 반전 토글 버튼

#### 4.2.4 Convert/Export (필수)

**기능 요구사항**:

- FR-I-EXPORT-01: 포맷 선택 (PNG, JPEG, WebP)
- FR-I-EXPORT-02: 브라우저 미지원 포맷은 UI에서 비활성화
  - `canvas.toDataURL('image/webp')` 결과로 런타임 판단
- FR-I-EXPORT-03: JPEG/WebP는 quality(0-100) 슬라이더 제공
- FR-I-EXPORT-04: 파일명 규칙:
  - 기본: `{originalName}.{ext}`
  - 선택적 suffix: `{originalName}{suffix}.{ext}`

**UI 요소**:

- 포맷 선택 드롭다운
- 품질 슬라이더 (JPEG/WebP 선택 시)
- 파일명 suffix 입력
- Export 버튼

### 4.3 프리뷰/출력 동작

#### 파일 로드 시

1. 원본 메타 정보 표시: 파일명, 용량, 가로×세로, 추정 포맷
2. 프리뷰 렌더링 (fit to container)
3. 파이프라인 설정은 이전 상태 유지 (crop 영역은 리셋)

#### 파이프라인 변경 시

1. 설정 변경 감지 (debounce 150~250ms)
2. 프리뷰 즉시 갱신
3. 예상 출력 크기 표시

#### Export 실행 시

1. enable된 단계 순서대로 처리:
   - Crop → Resize → Rotate/Flip → Format 변환
2. 최종 Blob 생성
3. 자동 다운로드 트리거

### 4.4 구현 제약/권장 구현

#### 이미지 디코딩

```typescript

const bitmap = await createImageBitmap(file);
const canvas = document.createElement('canvas');

canvas.width = bitmap.width;
canvas.height = bitmap.height;
```

```typescript
// Worker 내부
self.onmessage = async (e) => {

  const canvas = new OffscreenCanvas(width, height);
  const ctx = canvas.getContext('2d');
  // ... 처리 ...
  const blob = await canvas.convertToBlob({ type: 'image/png' });
  self.postMessage({ blob });
};
```

#### 포맷 지원 체크

```typescript
function isFormatSupported(format: string): boolean {
```

- **(AC-I3)** 마지막 사용 설정이 저장되어 재진입 시 옵션이 복원된다 (파일은 비어있어야 함)

**UI 요소** (프리뷰 영역 아래, 파이프라인 패널과 분리):

- 시간 입력 필드 (초 또는 mm:ss)

> 아래 단계들은 파이프라인의 일부로, 활성화된 단계들이 순서대로 실행되어 **하나의 비디오 파일**을 출력합니다.

##### 5.3.2.1 Trim (필수)

**기능 요구사항**:

- FR-V-TRIM-01: start/end 시간 지정 (초 단위 + mm:ss 입력 지원)
- FR-V-TRIM-02: 결과는 해당 구간만 남긴 단일 비디오
- FR-V-TRIM-03: 오디오도 동일 구간으로 편집 (기본 동작)
- FR-V-TRIM-04: 시크바에서 드래그로 구간 선택

**ffmpeg 명령어**:

```bash
ffmpeg -i input.mp4 -ss 10 -to 30 -c copy output.mp4
```

**UI 요소**:

- Start/End 시간 입력 필드
- 듀얼 핸들 시크바 (range slider)
- 선택 구간 미리보기

##### 5.3.2.2 Cut (필수)

**기능 요구사항**:

- FR-V-CUT-01: 두 가지 모드 제공
  - **구간 제거**: `[0~A] + [B~end]`로 이어붙여 단일 결과
  - **구간 분할**: 선택 구간 기준으로 N개 클립 생성
- FR-V-CUT-02: 분할 시 다중 파일은 zip으로 묶어 다운로드 (JSZip)
- FR-V-CUT-03: 시간 입력 형식: 초 단위 또는 mm:ss

**ffmpeg 명령어 (구간 제거)**:

```bash
# 방법 1: concat filter
ffmpeg -i input.mp4 -filter_complex \
  "[0:v]trim=0:10,setpts=PTS-STARTPTS[v1]; \
   [0:v]trim=20,setpts=PTS-STARTPTS[v2]; \
   [0:a]atrim=0:10,asetpts=PTS-STARTPTS[a1]; \
   [0:a]atrim=20,asetpts=PTS-STARTPTS[a2]; \
   [v1][a1][v2][a2]concat=n=2:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" output.mp4
```

**UI 요소**:

- 모드 선택 (Remove / Split)
- Cut 구간 시간 입력
- 시크바에서 구간 표시

##### 5.3.2.3 Crop (필수)

**기능 요구사항**:

- FR-V-CROP-01: 프리뷰 위에서 crop 영역 지정 (이미지 crop과 동일 UX)
- FR-V-CROP-02: 비율 프리셋 제공 (1:1, 16:9, 4:3 등)
- FR-V-CROP-03: 좌표 수치 입력 (x, y, width, height)

**ffmpeg 명령어**:

```bash
ffmpeg -i input.mp4 -filter:v "crop=640:480:100:50" output.mp4
```

**UI 요소**:

- 비율 선택 드롭다운
- 좌표 입력 필드
- 프리뷰 오버레이

##### 5.3.2.4 Resize (필수)

**기능 요구사항**:

- FR-V-RESIZE-01: 출력 해상도 지정 (예: 1280×720)
- FR-V-RESIZE-02: keep aspect toggle
- FR-V-RESIZE-03: 모드 선택 (contain/cover/stretch)

**ffmpeg 명령어**:

```bash

# 패딩 추가 (contain)
```

- Width/Height 입력

##### 5.3.2.5 Export/Convert (필수)

**기능 요구사항**:

- FR-V-EXPORT-01: 컨테이너 선택: MP4(기본), WebM

### 5.4 진행 상태(Progress) 표시 규격

#### 상태 단계

```typescript
type ProcessingState =
  | { stage: 'idle' }
  | { stage: 'loading'; message: string } // ffmpeg 코어 로딩
  | { stage: 'preparing'; message: string } // 파일 쓰기, 명령 생성
```

#### 진행률 산정

**1차: ffmpeg.wasm progress 이벤트**

```typescript
ffmpeg.on('progress', ({ progress, time }) => {
  // progress: 0~1 (일부 환경에서 부정확)
  // time: 처리된 시간 (마이크로초)
  setProgress(progress * 100);
});
```

**2차: 로그 기반 보완**

```typescript
ffmpeg.on('log', ({ message }) => {
  // "time=00:01:23.45" 파싱하여 진행률 계산
  const match = message.match(/time=(\d{2}):(\d{2}):(\d{2}\.\d{2})/);
  if (match) {
    const time =
      parseInt(match[1]) * 3600 +
      parseInt(match[2]) * 60 +
      parseFloat(match[3]);
    const progress = (time / totalDuration) * 100;
    setProgress(progress);
  }
});
```

**3차: 스피너 폴백**

- progress가 0/1만 뜨는 경우 → 스피너 + stage 표시

```typescript
let ffmpegInstance: FFmpeg | null = null;
let loadingPromise: Promise<void> | null = null;

export function useFFmpeg() {
  const [isLoading, setIsLoading] = useState(true);
  const [isReady, setIsReady] = useState(false);

  useEffect(() => {
    async function init() {
      if (!ffmpegInstance) {
        ffmpegInstance = new FFmpeg();
        loadingPromise = ffmpegInstance.load({...});
      }
      await loadingPromise;
      setIsLoading(false);
      setIsReady(true);
    }
    init();
  }, []);

  return { ffmpeg: ffmpegInstance, isLoading, isReady };
}
```

## 11. 테스트 케이스

### 11.1 Image Studio 테스트

1. **파일 로드**: PNG/JPEG/WebP 로드 및 메타 정보 표시
2. **Drag & Drop**: 파일 드롭으로 이미지 로드
3. **Clipboard Paste**: Ctrl+V로 클립보드 이미지 붙여넣기
4. **Crop**: 자유비율/고정비율 crop 영역 지정 및 적용
5. **Resize**: 비율 잠금 on/off 동작, 모드별 결과 확인
6. **Rotate/Flip**: 90° 회전 및 반전 조합 적용
7. **Export**: PNG/JPEG/WebP 변환, 품질 조절 결과 확인
8. **Pipeline**: Crop + Resize + Export 조합 실행
9. **Preset**: 프리셋 저장/불러오기/공유
10. **모바일**: 터치로 crop 영역 조절
11. **대용량 파일**: 10MB 이미지 처리 시 UI 응답성

### 11.2 Video Studio 테스트

1. **ffmpeg 로드**: 코어 로딩 및 Ready 상태 전환
2. **파일 로드**: MP4/WebM 로드 및 메타 정보 표시
3. **Thumbnail**: 지정 시간 프레임 추출
4. **Trim**: 시작/종료 시간 지정 구간 추출
5. **Cut Remove**: 구간 제거 후 단일 비디오 생성
6. **Cut Split**: 구간 분할 후 zip 다운로드
7. **Crop**: 비디오 프레임 crop 적용
8. **Resize**: 해상도 변경 적용
9. **Export**: MP4/WebM 변환, 품질 프리셋 적용
10. **Progress**: 진행률 표시 및 업데이트
11. **Cancel**: 처리 중 취소 동작
12. **Pipeline**: Trim + Crop + Resize 조합 실행
13. **모바일**: 터치로 타임라인 조작
14. **대용량 경고**: 300MB 이상 파일 경고 표시

## 16. 용어 정의

| 용어            | 정의                                                        |
| --------------- | ----------------------------------------------------------- |
| Pipeline        | 여러 편집 단계를 순서대로 조합하여 일괄 실행하는 워크플로우 |
| Preset          | 파이프라인 설정을 저장한 JSON 데이터                        |
| Crop            | 이미지/비디오의 특정 영역만 잘라내는 작업                   |
| Trim            | 비디오의 시작/종료 시간을 지정하여 구간을 추출하는 작업     |
| Cut             | 비디오의 특정 구간을 제거하거나 분할하는 작업               |
| Thumbnail       | 비디오의 특정 프레임을 이미지로 추출하는 작업               |
| ffmpeg.wasm     | 브라우저에서 실행 가능한 ffmpeg의 WebAssembly 버전          |
| OffscreenCanvas | Worker에서 사용 가능한 Canvas API                           |
